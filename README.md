💻 Running the Projects

Clone the repository:

git clone https://github.com/sanarajini/full-stack-training.git

Move into the repository:

cd full-stack-training

For a React project, move into the required project folder:

cd "module 4/react-portfolio"

Install dependencies:

npm install

Start the development server:

npm run dev

The exact command may vary depending on the project configuration.
